La herramienta · VS Code

¿Qué es VS Code?

Un editor gratuito de Microsoft para Windows, macOS y Linux. No es «solo para programadores»: es una mesa de trabajo para cualquier archivo de texto, y en él vive también la IA.

  1. Barra de actividad: explorador, buscar, Git, depurar y extensiones.
  2. Explorador: VS Code abre carpetas, no solo archivos. Tu proyecto entero a la vista.
  3. Editor: colores, autocompletado y avisos de errores mientras escribes.
  4. Terminal: la «línea de comandos», dentro del propio editor.
  5. Chat de IA: le pides cosas en español y ve tus archivos.
  6. Barra de estado: qué Python estás usando, en qué línea estás…

Entender los archivos

Archivos de texto y archivos binarios

Todo archivo son ceros y unos. La diferencia es si esos bytes son letras que una persona puede leer o un formato que solo entiende su programa.

Manos a la obra · 1 de 4

Instalar Python con Miniforge

Miniforge trae Python y conda, que instala librerías y las organiza en «entornos». Es gratuito y sin las restricciones de licencia de Anaconda.

Windows

  1. Entra en github.com/conda-forge/miniforge y descarga Miniforge3-Windows-x86_64.exe.
  2. Instálalo con las opciones por defecto («Just Me»).
  3. En el menú Inicio abre Miniforge Prompt.
  4. Para usar conda también en la terminal de VS Code:
conda init powershell

macOS (y Linux)

  1. Abre la app Terminal y pega:
curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh
  1. Acepta la licencia y responde yes a todo.
  2. Cierra la terminal y abre una nueva.
✅ Comprobación en los dos sistemas: escribe conda --version. Si responde algo como conda 25.x, está listo.

Manos a la obra · 2 de 4

El entorno profesia, y decírselo a VS Code

Un entorno es una caja de herramientas por proyecto: su versión de Python y sus librerías, sin mezclarse con las de otros proyectos.

En la terminal

# el primer día: crear el entorno «profesia» con Python
conda create -n profesia python=3.12 -y
# hoy: añadirle las librerías del curso (desde la carpeta ProfesIA)
conda install -n profesia -c conda-forge --file requirements.txt -y
# entrar en el entorno (cada vez que abras una terminal nueva)
conda activate profesia

¿Falta una librería más adelante? conda install -n profesia scipy

En VS Code

  1. Descarga el material: github.com/GeoOcean/ProfesIA → Code → Download ZIP, y descomprímelo.
  2. Archivo → Abrir carpeta… → la carpeta ejemplos.
  3. Abre scripts/viga.py. Pulsa Ctrl+Shift+P → Python: Select Interpreter → elige profesia.
  4. En un notebook, arriba a la derecha: Select Kernel → profesia.
👀 Si abajo a la derecha pone 3.12 ('profesia'), VS Code está usando tu entorno.

Ejecutar un script y un notebook

El mismo cálculo, la flecha de una viga en voladizo, de dos formas. Las dos usan el mismo Python del entorno profesia.

viga.py▶ Run Python File
import numpy as np

L = 3.0       # longitud [m]
P = 10e3      # carga en el extremo [N]
E = 210e9     # acero [Pa]
I = 1943e-8   # IPE 200 [m⁴]

x = np.linspace(0, L, 100)
flecha = P * x**2 * (3*L - x) / (6*E*I)
print(f"Flecha máxima: {flecha.max()*1000:.1f} mm")
Script (.py): se ejecuta entero de arriba abajo con ▶, o en la terminal con python scripts/viga.py. Ideal para cálculos que repites.

Depurar: parar el programa y mirar dentro

Cuando algo sale mal, no hace falta llenar el código de print. El depurador congela el programa en una línea y te enseña el valor de cada variable.

Variables L3.0 P10000.0 E210000000.0 ← ¡faltan tres ceros! (210 GPa = 210e9) I1.943e-05
  1. Abre viga_con_error.py y ejecútalo: dice que la flecha es de 22 m. Algo falla.
  2. Pulsa en el margen, a la izquierda del número de línea: aparece un punto rojo (punto de interrupción).
  3. Pulsa F5 → Python Debugger: Current File. El programa se para en el punto rojo.
  4. Mira el panel Variables: E vale 210 millones, no 210 000 millones.

Todo junto

Pedirle cosas a la IA dentro de VS Code

Abre el chat de tu extensión, con la carpeta ejemplos abierta. Escribe en español, como a un compañero. La IA ve tus archivos y propone cambios que tú aceptas o rechazas.

1 · Entender «Explícame qué hace viga.py línea a línea, como si no supiera Python.» Ideal para heredar código de un compañero o de un TFG.
2 · Ampliar «Añade a viga.ipynb una celda que dibuje también el momento flector y guarde la figura en PNG.» Verás los cambios marcados en verde y rojo antes de aceptarlos.
3 · Arreglar «viga_con_error.py da una flecha 1000 veces mayor de lo esperado. ¿Dónde está el error?» Compara su respuesta con lo que encontraste con el depurador.
🎯Da contexto. Di qué archivo, qué esperas y qué obtienes.
🪜Pide por pasos. Mejor tres peticiones pequeñas que una enorme.
🔍Revisa siempre. La IA se equivoca con seguridad; tú eres el ingeniero.

Con Copilot Student: cada mensaje del chat gasta créditos (200 al mes, se reponen el día 1); el autocompletado no gasta. Deja el modelo en Auto y pide cosas concretas.
