# Deck de Fernando: ¿Cómo utilizar la IA en Ingeniería Civil?

Versión resumida (16 diapositivas) de las dos presentaciones de Fernando Méndez:
«IA Master ICCP» (75 diapositivas, la charla general) e «IceCube6» (137, la
propuesta de proyecto de bloques de cálculo). Los `.pptx` originales se dejan en
esta carpeta pero no se suben a git (pesan ~300 MB).

Abre `deck-fer/index.html` en el navegador. Usa el mismo tema y motor que
`deck/` (`../deck/style.css` y `../deck/deck.js`); `fer.css` solo añade los
componentes propios (calculadoras, círculos, mapa de algoritmos, niveles…).
